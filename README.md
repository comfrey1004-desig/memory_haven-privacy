# Memory Haven privacy policy

GitHub Pages site for the Memory Haven (기억건축소) privacy policy.

- index.html opens the policy in the visitor's language
- privacy-policy-ko.html (한국어)
- privacy-policy-en.html (English)

To add a language, copy privacy-policy-en.html to privacy-policy-<code>.html,
translate it, add it to the pages map in index.html and to the links at the
top of each policy page.
